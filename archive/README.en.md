# Historical Archive

[Español](README.md) | **English**

`youtube-sync-legacy` preserves the previous application for historical reference.
It is not part of active development or current YouTubeSync builds.

The only active project is `outputs/youtube-sync-modern`, which has its own
engine and imports no code from this archive. Start the current application
using `Abrir-YouTubeSync.cmd` at the repository root.

`local-data` contains only local backups recovered from old tests. It may
contain tokens or browser profile data: never publish it, import it automatically
or confuse it with active `%APPDATA%\YouTubeSync` data. It is excluded from Git.

The historical `youtube-sync-legacy` distribution is preserved locally; its
Python environment and build caches can be regenerated by its build script.
