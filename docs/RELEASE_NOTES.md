# YouTubeSync 1.0

## Español

Primera versión completa para Windows, con instalador y actualizaciones desde la app.

- Biblioteca de vídeos con columnas configurables, estados e iconos.
- Subida manual o automática, cancelación, revisión y reintentos controlados.
- Conexión guiada a tu canal con tus propias credenciales de Google.
- Confirmaciones persistentes y comparación guiada entre archivo local y YouTube.
- Gestión del canal: búsqueda, filtros, listas, privacidad, compartir y duplicados.
- Limpieza local con comprobaciones de seguridad y revisión de vídeos cortos.
- Español e inglés, bandeja, avisos accionables y consola de diagnóstico.
- Próximas versiones instalables desde Ajustes, conservando autorización y registros.

Descarga **YouTubeSync-1.0-windows-x64-setup.exe**. No necesitas Python.
El instalador no tiene firma Authenticode propia. Se incluye `SHA256SUMS.txt`.
Las cuotas y restricciones de YouTube siguen siendo aplicables; la app no las evita.

## English

First complete Windows release, with installer and in-app updates.

- Video library with configurable columns, states and icons.
- Manual/automatic uploads, cancellation, review and controlled retries.
- Guided channel connection using your own Google credentials.
- Persistent confirmations and guided local/YouTube comparison.
- Channel search, filters, playlists, visibility, sharing and duplicate review.
- Checked local cleanup and short-video review.
- Spanish/English, tray controls, actionable guidance and diagnostic Console.
- Future updates install from Settings while preserving authorization and records.

Download **YouTubeSync-1.0-windows-x64-setup.exe**. Python is not required.
The installer has no publisher-owned Authenticode signature. `SHA256SUMS.txt` is included.
YouTube quotas and restrictions still apply; the app does not bypass them.
