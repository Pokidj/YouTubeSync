# YouTubeSync Brand / Marca

## Español

El usuario eligió la propuesta **B**, un monograma S con flechas opuestas y espacio
negativo de reproducción. Las propuestas se crearon con el generador de imágenes
integrado. El arte de producción se reconstruyó en SVG para conseguir bordes
limpios, transparencia real y tamaños pequeños legibles, sin usar la extracción
raster como recurso definitivo.

- Original editable: `youtube-sync-logo.svg`.
- PNG generado: `youtube-sync-logo.png` (1024 x 1024).
- Icono Windows: `youtube-sync.ico` (16, 20, 24, 32, 48, 64, 128 y 256 píxeles).
- Regeneración: `.venv/Scripts/python.exe -B scripts/build_brand_assets.py`.
- No se usa el emblema oficial de YouTube ni se indica afiliación con Google.

## English

The user selected **B**, an S monogram with opposing arrows and play-shaped
negative space. Concepts were produced with the built-in image generator. The
production artwork was reconstructed as SVG for clean edges, genuine transparency
and small-size legibility, rather than using the raster extraction as a final asset.

The SVG is canonical. `scripts/build_brand_assets.py` exports its PNG and eight
native Windows ICO sizes. This is the application's own mark, not YouTube's
official emblem or a claim of Google affiliation.

No gradients, no gloss, no 3D, no shadows, no browser/app mockups, no decorative backgrounds, no stock imagery. Balanced crisp design comparison with generous spacing, no extra slogans or watermarks.
