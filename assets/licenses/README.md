# Avisos de terceros / Third-Party Notices

## Español

YouTubeSync utiliza Python, PySide6/Qt y bibliotecas de Google y otros autores.
El instalador incluye sus avisos disponibles en `_internal/licenses`. Los iconos
Lucide tienen atribución y licencia en `assets/icons`. Los textos LGPL y GPL
acompañan la distribución para las bibliotecas Qt que se ofrecen bajo esas licencias.

PySide6/Qt se carga como bibliotecas independientes. Puede sustituirse por una
compilación compatible; no se impide su modificación ni depuración. El código
fuente de las bibliotecas está disponible en
[Qt for Python](https://code.qt.io/cgit/pyside/pyside-setup.git/) y
[Qt](https://code.qt.io/cgit/qt/), usando las versiones indicadas en `requirements.txt`.
Los avisos de terceros no asignan una licencia nueva al código propio de YouTubeSync.

## English

YouTubeSync uses Python, PySide6/Qt, Google libraries and other dependencies.
Available dependency notices are bundled in `_internal/licenses`. Lucide icon
attribution/license is in `assets/icons`. LGPL/GPL texts accompany the Qt libraries
offered under those licenses.

PySide6/Qt loads as independent libraries and may be replaced by a compatible
build; modification and debugging are not restricted. Library source is available
from [Qt for Python](https://code.qt.io/cgit/pyside/pyside-setup.git/) and
[Qt](https://code.qt.io/cgit/qt/), for versions listed in `requirements.txt`.
Third-party notices do not assign a new license to YouTubeSync's own code.
